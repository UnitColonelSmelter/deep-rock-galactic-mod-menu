## 🧩 About

**Deep Rock Galactic Companion** is a curated list of Deep Rock Galactic open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, mission timer
- **Quality-of-Life Helpers** — loadout catalog, perk manager, overlay notes
- **Research Notes** — cave layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Mission Helpers
- Mission Timer — track time spent in caves
- Resource Tracker — monitor nitra, gold, and crafting materials
- Enemy overlay — show nearby hostile positions on overlay
- Quick Deposit — notes for faster mineral deposit

### 🎨 Loadout & Cosmetics
- Loadout Catalog — browse weapons, overclocks, and cosmetics
- Custom Skin Notes — organize dwarf cosmetics
- Perk Manager — view and plan active perks

### 🏋️ Cave Layout
- Map Overlay — display cave layout and terrain scanner
- Gravity Flip Control — notes for low-gravity environments
- Jump Buffer Notes — chain complex maneuvers in solo play
